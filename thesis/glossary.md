# Glossary

## Embedded Systems

\begingroup
\setlength{\parindent}{0pt}
\begin{singlespace}
\textbf{Actuator} - A component of a machine that is responsible for moving
and controlling a mechanism or system  \\

\textbf{APT} - Advanced Package Tool - A package management tool used to
install, update, and remove software on Debian-based Linux systems  \\

\textbf{BitBake} - A build engine used by the Yocto Project to execute
build tasks and recipes for creating Linux distributions and software
packages  \\

\textbf{Carrier Board} - A printed circuit board that connects a SoM to
external interfaces, peripherals, and power  \\

\textbf{Bootloader} - A small piece of code that runs immediately after a
system powers on  \\ It initializes the hardware and loads the main
operating system or firmware application into memory  \\

\textbf{CPU} - Central Processing Unit - The primary component of the
computer that acts as the "brain" of the device executing instructions  \\

\textbf{Edge Computing} - A distributed computing paradigm where data
processing is performed directly on physical hardware devices (at the
"edge" of the network) close to where the data is collected, rather than
sending it to a centralized cloud or data center  \\

\textbf{eMMC} - Embedded MultiMediaCard - Non-volatile flash storage
soldered onto a device's circuit board  \\

\textbf{Firmware} - Specific class of computer software that provides the
low-level control for a device's specific hardware  \\

\textbf{Flash Memory} - A type of non-volatile computer storage medium that
can be electrically erased and reprogrammed  \\

\textbf{GIT} - A distributed version control system used to track changes
to source code and coordinate development  \\

\textbf{GPIO} - General-Purpose Input/Output - Uncommitted digital signal
pins on an integrated circuit or electronic circuit board whose behavior
can be controlled by the user at runtime  \\

\textbf{Interrupt} - A signal to the processor emitted by hardware or software
indicating an event that needs immediate attention  \\

\textbf{IoT} - Internet of Things - A network of physical objects ("things")
embedded with sensors, software, and processing units (like MCUs or SoCs)
that connect and exchange data with other devices and systems over the
internet  \\

\textbf{MCU} - Microcontroller - Compact integrated circuit designed for
a specific operation in an embedded system  \\

\textbf{PCB} - Printed Circuit Board - A board that supports electronic
components and connects them with conductive traces; SoMs and carrier
boards are examples of PCBs  \\

\textbf{PIP} - The package installer for Python, used to install and manage
Python packages and their dependencies  \\

\textbf{RAM} - Random Access Memory - Volatile memory that temporarily
holds data and programs currently in use by the processor  \\

\textbf{RTOS} - Real-Time Operating System - An operating system intended to
serve real-time applications that process data as it comes in  \\

\textbf{SD} - Secure Digital - A removable flash memory card commonly
used for storage in embedded devices  \\

\textbf{Sensor} - A device that detects and responds to some type of input
from the physical environment  \\

\textbf{SoC} - System on Chip - An integrated circuit that integrates all
components of a computer or other electronic system into a single chip  \\

\textbf{SoM} - System on Module - A small electronic circuit board that
contains a core computer system—including an SoC, external RAM, storage,
and power management—designed to be plugged into a larger carrier board  \\

\textbf{SSH} - Secure Shell - A network protocol for securely connecting to
and managing remote systems, commonly used to access embedded Linux
devices  \\

\textbf{UART} - Universal Asynchronous Receiver-Transmitter - A physical
circuit or communication protocol used for asynchronous serial
communication, allowing devices to talk to each other using two wires  \\

\textbf{Yocto Project} - An open-source project and set of tools for
creating custom Linux-based operating system images for embedded devices  \\

\end{singlespace}
\endgroup

## Artificial Intelligence 

\begingroup
\setlength{\parindent}{0pt}
\begin{singlespace}
\textbf{AI} - Artificial Intelligence - The broader concept of machines
being able to carry out tasks in a way that mimics human intelligence,
reasoning, or problem-solving  \\

\textbf{Algorithm} - A set of step-by-step mathematical rules or
instructions given to an AI system to help it learn from data
or solve a specific problem  \\

\textbf{Backpropagation} - The foundational algorithm used to train neural
networks by calculating the error at the output layer and passing it
backward through the network to adjust the connection weights and improve
accuracy  \\

\textbf{Bias} - Systematic errors in an AI system caused by flawed
assumptions in the ML process or unrepresentative training data  \\

\textbf{Computer Vision} - A field of AI that trains computers to interpret
and understand the visual world  \\

\textbf{DL} - Deep Learning - A specialized subfield of ML that utilizes
multi-layered artificial neural networks to solve complex problems  \\

\textbf{Edge Computing} - The practice of running machine learning models
and processing data locally on physical hardware devices (like sensors or
microcontrollers) rather than relying on a cloud server, enabling instant
predictions, lower latency, and increased privacy  \\

\textbf{FQT} - Fully Quantized Training - A training method where both the
forward and backward passes of a neural network are calculated using low-bit
mathematical formats (like 8-bit integers instead of 32-bit floating points)
to drastically reduce memory usage and accelerate training  \\

\textbf{Inference} - The process of using a trained ML model to make
predictions or decisions on new, unseen real-world data  \\

\textbf{LLM} - Large Language Model - A deep learning model trained on
massive amounts of text data, capable of understanding, generating, and
translating human language  \\

\textbf{ML} - Machine Learning - A subset of AI focused on building systems
that learn from data, identify patterns, and make decisions with minimal
human intervention  \\

\textbf{Model} - The output generated by an ML algorithm after training
on a dataset It represents what the system has learned and is used to
make predictions on new data  \\

\textbf{Neural Network} - A computing system inspired by the biological
neural networks of the human brain, consisting of interconnected nodes  \\

\textbf{Overfitting} - A common mistake where a model learns the training
data too well, memorizing the noise and details instead of the general
patterns, making it perform poorly on new data  \\

\textbf{Supervised Learning} - A type of ML where the model is trained
on labeled data  \\

\textbf{Training Data} - The initial dataset used to teach an ML model
how to find patterns, make predictions, or perform a specific task  \\

\textbf{Underfitting} - A scenario where a model is too simple to capture
the underlying patterns in the data, resulting in poor performance on both
the training and new data  \\

\textbf{Unsupervised Learning} - A type of ML where the model analyzes
unlabeled data to discover hidden patterns or groupings on its own  \\

\end{singlespace}
\endgroup
